# LAB03 Hệ thống quản lý khách sạn

## Kết quả đã thực hiện

- Tạo database `QuanLyKhachSan` trên SQL Server `GOD_MG_999` gồm 19 bảng, đầy đủ khóa chính, khóa ngoại, ràng buộc và dữ liệu mẫu.
- Thiết kế giao diện C# Windows Forms App trên .NET Framework 4.7.2.
- Hoàn thành 8 màn hình: đăng nhập, tổng quan, danh mục, phòng - tiện nghi, đặt - nhận phòng, dịch vụ, trả phòng - thanh toán và thống kê.
- Chuẩn hóa giao diện tiếng Việt theo tông xanh dương; các Form có file `.Designer.cs` và `.resx` để chỉnh sửa trong Visual Studio Designer.
- Thêm giao diện tìm phòng trống, CRUD danh mục, dashboard, thanh toán và xem trước hóa đơn.
- Kết nối giao diện với SQL Server bằng ADO.NET, truy vấn có tham số và transaction.
- Hoàn thiện đăng nhập PBKDF2, phân quyền, tải dữ liệu, CRUD, đặt/nhận phòng, dịch vụ, hóa đơn, thanh toán, trả phòng và thống kê.
- Project đã được build và chạy thử thành công bằng Visual Studio Community 2022.

## Thông tin chạy thử

- Tài khoản giao diện mẫu: `admin`
- Mật khẩu: `123`
- Project: `QuanLyKhachSan/QuanLyKhachSan.sln`

## Bước tiếp theo
