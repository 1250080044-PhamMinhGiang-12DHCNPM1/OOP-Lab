## 🚀 Dự án

### 📚 LAB_AT_OOSD — Bài thực hành phân tích thiết kế hướng đối tượng

Bộ bài tập LAB01–LAB07 về phân tích nghiệp vụ, thiết kế UML và hiện thực ứng dụng. Các bài có báo cáo và sơ đồ; một số bài có mã nguồn C# WinForms và cơ sở dữ liệu SQL Server.

| Bài lab | Chủ đề |
|---|---|
| [LAB01](./LAB01/) | Buổi học đầu tiên về phương pháp phát triển phần mềm hướng đối tượng |
| [LAB02](./LAB02/) | Hệ thống quản lý thư viện |
| [LAB03](./LAB03/) | Hệ thống quản lý khách sạn |
| [LAB04](./LAB04/) | Hệ thống mua sắm trực tuyến e-SHOPPING |
| [LAB05](./LAB05/) | Quản lý công ty du lịch |
